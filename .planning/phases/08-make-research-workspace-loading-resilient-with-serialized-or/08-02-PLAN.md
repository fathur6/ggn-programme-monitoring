</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/client → aggregate RPC | Caller-supplied programme identity requests a composite workspace snapshot. |
| Aggregate service → Auth/Programme services | One canonical identity and authorization decision controls every capability envelope. |
| Aggregate service → Sheets | Shared setup/migration and range capture interact with mutable shared rows under the script lock. |
| Server logs → operators | Endpoint diagnostics must not expose Sheet/schema internals to clients. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-05 | Elevation of privilege | `getResearchWorkspaceApi_` | high | mitigate | Require existing research programme authorization and canonical composite identity before snapshot composition; reject non-research and ambiguous access. |
| T-08-06 | Information disclosure | Endpoint envelopes/logging | medium | mitigate | Separate stable endpoint/error codes and safe messages from server-only diagnostics; never return another programme's snapshot. |
| T-08-07 | Tampering | Aggregate read projection | medium | mitigate | Capture rows under the shared setup boundary, project outside the lock without write helpers, and test before/after Sheet equality. |
| T-08-08 | Denial of service | Shared setup/read critical section | high | mitigate | Batch setup/capture once, keep pure projection outside the lock, and use the bounded helper from 08-01. |
| T-08-09 | Tampering | Assessment mapping/review aggregation | high | mitigate | Reuse existing projection and strict review validation from one authorized context; do not alter mutation or provenance semantics. |
| T-08-SC | Tampering | Package-manager installs | low | accept | No new package is planned; tests use existing Node built-ins and Apps Script APIs. |
